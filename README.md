# NEXORA RADAR · Sitio informativo

Este repositorio contiene **solo** una página informativa pública y su política de privacidad. **No contiene** el software privado NEXORA, código Python, bases de datos, modelos de IA, credenciales ni tokens.

## Archivos
- `index.html`: presentación pública.
- `privacidad.html`: política de privacidad y alcance de la posible integración con Pinterest.
- `styles.css`: estilos locales. No se utilizan trackers ni dependencias externas.

## Publicación
1. Crear un repositorio público **nuevo** `nexora-info` (sin cambiar la visibilidad de `nexora-web`).
2. Añadir a su rama `main` estos cuatro archivos en la raíz.
3. Abrir Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/(root)` → Save.
4. Verificar la web y la política desde una ventana de incógnito.

URL prevista, tras publicación: `https://eediazp1970.github.io/nexora-info/`
Política prevista: `https://eediazp1970.github.io/nexora-info/privacidad.html`
