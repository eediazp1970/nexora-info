Política de privacidad.

Esta política explica el alcance de este sitio informativo y el estado actual de las integraciones externas de NEXORA RADAR.

Última actualización: 18 de noviembre de 2026

1. Responsable y contacto

NEXORA RADAR es un proyecto de software local en desarrollo. La publicación de esta web informativa está administrada por el titular de la cuenta de GitHub eediazp1970. NEXORA es la denominación del proyecto y no implica, por sí misma, la constitución de una sociedad mercantil.

Para consultas generales puede utilizarse la información de contacto que el titular haya decidido publicar en su perfil de GitHub. No incluya contraseñas, tokens ni datos sensibles en canales públicos. Antes de habilitar una integración para terceros, se facilitará un canal directo adecuado para solicitudes de privacidad.

2. Datos tratados por esta web

Este sitio está compuesto por páginas estáticas. No contiene formularios, registros de usuarios, píxeles publicitarios, servicios de analítica propios ni cookies de seguimiento propias. No solicita credenciales de Pinterest ni de otras plataformas.

El sitio se aloja en GitHub Pages. GitHub puede procesar información técnica, incluida la dirección IP, y conservar registros con fines de seguridad y operación del servicio. Consulte la declaración de privacidad de GitHub.

3. Aplicación local y datos de investigación

NEXORA RADAR se ejecuta localmente en Windows y permite conservar investigaciones y evidencias en el entorno del propietario. El contenido concreto depende de las fuentes consultadas y de la configuración utilizada. Las señales de interés, ofertas observadas y clasificaciones se distinguen de las ventas verificadas.

Este sitio no ofrece acceso a las bases de datos, al código de la aplicación ni a los resultados privados del propietario.

4. Integración prevista con Pinterest

La conexión de NEXORA RADAR con la API de Pinterest aún no está activa. Se está evaluando una solicitud para acceder únicamente a información de tendencias de búsqueda y categorías comerciales que Pinterest autorice expresamente.

Si en el futuro se habilita una integración, el acceso se realizará mediante los permisos oficiales correspondientes, sin solicitar la contraseña de Pinterest al usuario. Cualquier identificador, token de autorización o dato autorizado deberá tratarse conforme a los permisos otorgados y a las condiciones de Pinterest, con medidas de protección locales y posibilidad de revocación según el mecanismo de acceso finalmente aprobado. Los detalles de implementación se actualizarán antes de su puesta en servicio.

No se pretende utilizar datos de Pinterest para entrenar modelos de inteligencia artificial, publicar contenido o realizar campañas publicitarias mediante esta conexión. La existencia de una cuenta empresarial no implica acceso aprobado a Pinterest Trends.

5. Cesiones, venta de datos y servicios externos

Este sitio no comercializa datos personales ni transmite formularios a NEXORA. Al visitar páginas enlazadas desde aquí, como GitHub o Pinterest, pueden aplicarse las condiciones de privacidad de sus respectivos operadores.

La investigación local de NEXORA puede necesitar conectividad con fuentes externas autorizadas. Las consultas realizadas a dichas fuentes quedan sujetas a sus propias condiciones y políticas.

6. Conservación, control y cambios

Esta web no crea cuentas de visitantes ni mantiene historiales personales propios. Los datos de investigación del software local dependen de la instalación y de las funciones de exportación, revocación y conservación disponibles para su propietario.

La presente política se actualizará cuando se habiliten nuevas integraciones o cambie sustancialmente el tratamiento de información. No se declarará autorizada una integración antes de obtener los permisos aplicables.

7. Alcance

La página tiene carácter informativo y no es una tienda ni un servicio de venta. Los análisis de productos son orientativos, no garantías de ventas, legalidad, disponibilidad, stock o rentabilidad.
